## Главная находка: README врал про качество модели

Раздел «Описание ML-модели» заполнялся на этапе 03–04 и остался нетронутым,
пока модель переобучалась ещё три раза — после исправления утечек в данных
(этапы 06–07) и после добавления `feature_baseline`.

| Метрика | README заявлял | Модель даёт |
|---|---|---|
| ROC-AUC | 0.9959 | **0.991** |
| PR-AUC | 0.9233 | **0.9148** |
| Precision | 0.9619 | **0.9351** |
| Recall | 0.7749 | **0.8191** |
| F1 | 0.8584 | **0.8733** |
| TP / FP / FN / TN | 303 / 12 / 88 / 19 469 | **317 / 22 / 70 / 19 463** |

Расхождение небольшое по величине, но неприятное по сути: документ уверенно
сообщал числа, которых система не показывает. Причём часть изменений —
в лучшую сторону (recall вырос с 0.775 до 0.819), то есть README занижал
реальный результат.

Опасность здесь не в конкретных цифрах, а в том, что **заметить устаревание
можно было только случайно**. Ничто не связывало текст README с артефактом
модели.

## Durable-решение: сверка стала автоматической

Исправить числа — половина работы. Через два переобучения они устареют снова.

Поэтому добавлен `backend/scripts/check_docs.py`. Он превращает молчаливое
устаревание в громкую ошибку: завершается с ненулевым кодом при любом
расхождении.

| Утверждение в README | Источник правды |
|---|---|
| метрики модели | `backend/models/model_metrics.json` |
| результаты сценариев | `docs/HAND_TESTING.md` |
| число признаков | реестр `app/features/definitions.py` |
| число сценариев | `app/services/scenarios.py` |
| упомянутые скрипты | содержимое `backend/scripts/` |
| локальные ссылки | файлы на диске |
| 15 обязательных разделов | ТЗ §14 |

```bash
python backend/scripts/check_docs.py
```

**Почему не генерировать README целиком.** `docs/FEATURES.md` и
`docs/HAND_TESTING.md` генерируются, и это правильно: они табличные.
README — связный текст с объяснениями решений, генератор превратил бы его
в свалку. Поэтому текст остаётся рукописным, а числа в нём проверяются.

### Проверка проверки

Сверка бесполезна, если не ловит того, ради чего написана. Поэтому в README
временно внесены три искусственных расхождения — по одному на класс:

```
[FAIL] Метрики модели
       - метрика ROC-AUC: в артефакте 0.991, в README её нет
[FAIL] Результаты сценариев
       - сценарий 4 «Large amount»: 73/BLOCK — в README другое значение
[FAIL] Ссылки на файлы
       - битая ссылка на docs/NOPE.md
```

Все три пойманы, README восстановлен, проверка снова зелёная.
